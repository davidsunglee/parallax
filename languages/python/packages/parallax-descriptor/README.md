# parallax-descriptor

Parallax descriptor interchange over `parallax-core`: canonical model-descriptor ingestion and export. See the [Python binding](https://github.com/davidsunglee/parallax/blob/main/languages/python/spec/python.md).

Install this distribution with `python -m pip install parallax-descriptor==0.2.0`.
Its metadata installs exact matching first-party dependencies. The
[getting-started guide](https://github.com/davidsunglee/parallax/blob/main/languages/python/docs/guide/01-getting-started.md#install)
explains application composition and supported environments; the
[release notes](https://github.com/davidsunglee/parallax/blob/main/languages/python/docs/releases.md) record publication status.
