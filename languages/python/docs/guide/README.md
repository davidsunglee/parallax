# Parallax Python Guide

This guide teaches the Python API task by task, from a first program to the advanced
cases. Every example is executed against PostgreSQL by the API Conformance Suite, so the
code shown here runs as written. The [Python binding](../../spec/python.md) owns the API
contracts, and the [PostgreSQL lifecycle guide](../postgresql-lifecycle.md) covers
running Parallax in production.
